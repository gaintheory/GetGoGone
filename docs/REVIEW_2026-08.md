# Project Review — August 2026

A full read of the codebase, migrations and docs, with a build and lint run.
Companion to `docs/REDESIGN_2026-06.md`, which already diagnosed most of the
structural problems correctly. This document records what was found, what was
fixed in this pass, and what is still open.

## Overall read

Not a mess — a well-built demo with a real backend bolted on halfway, carrying
three eras of itself at once. The build passes. Per-file code quality is decent.
The problem is that the June cleanup was staged and never executed, so the app is
running in the awkward middle.

The gap that matters: the demo surface massively outruns the working surface, and
that gap was invisible from inside the UI because the mocks were too convincing.

## Open — needs a decision

### 1. Authentication (blocking before any dealer logs in)

There are no users. One shared `SITE_PASSWORD`; the cookie carries no identity.
`profiles` exists with a `role` column and ~10 tables carry `created_by` /
`assigned_to` FKs pointing at it, all permanently null. RLS is enabled everywhere
with zero policies, and the service-role key bypasses it regardless.

Either wire Supabase Auth to `profiles` and write real RLS policies, or delete
`profiles` and the dangling FKs and record that GGG is single-tenant by design.
The current middle state has the cost of multi-user with none of the benefit.

### 2. The staged deletions

`REDESIGN_2026-06.md` lists these for removal, blocked on the `POST /leads`
decision. Still present:

- Inventory intake (`features/inventory/intake/*`, CSV/VIN/ZIP/manual routes) — ~1,200 lines AutoDoss now owns
- Leads screen + `leads` / `lead_activities` tables
- Test Drive screen
- `AGENCY_ROADMAP.md`, `AGENTIC_IMPLEMENTATION_STRATEGY.md`, `agency_transformation_proposal.md` (~58 KB superseded)

Nav is still 16 items with a section literally labelled `AutoDoss-owned` — the
label for the deletion shipped without the deletion.

### 3. `POST /api/v1/leads` on AutoDoss

Still the missing rung. Until it exists, GGG keeps a shadow copy of vehicles
(`upsertVehicle` on campaign save) and its own leads tables, and the split-brain
regenerates faster than it can be cleaned.

### 4. Redundancy

Five screens compete to be the home page: Agency, Cockpit, Dashboard, Conveyor,
Vehicle Hub. Four routes are defined but never called by any UI
(`campaigns/recommendations`, `creative-exports`, `distribution/feed`,
`inventory/readiness`). Every screen file is reachable — there is no dead UI.

### 5. Lint — 100 errors / 70 warnings (was 102 / 77)

The build does not gate on lint. The bulk of the errors are `no-explicit-any`,
and investigating them showed they are not laziness: `supabase as any` was added
to silence a genuine friction where `Record<string, unknown>` will not assign to
a `jsonb` column's `Json` type. The cast fixes that one complaint by switching
off type checking for **every** column in the statement, including the ones that
are actually wrong.

The honest fix and the pattern to follow are now in place:

- `src/lib/json.ts` — `toJson()` / `toJsonObject()` narrow arbitrary parsed JSON
  to the `Json` type, dropping non-representable values and handling circular refs.
- `src/app/api/leads/inbound/route.ts` is converted as the reference. It is the
  public, unauthenticated endpoint, so it was the highest-value target. It now has
  no `as any` and typechecks fully against the generated Supabase types.

Remaining: roughly 30 `supabase as any` / `client as any` casts across ~17 route
files, and 12 `let body: any = {}` request-body declarations. Each conversion is
small and independent — apply the reference pattern per file, then run
`npx tsc --noEmit`. The `body: any` cluster is worth more than its lint count
suggests: those are unvalidated request bodies at API boundaries.

`npx tsc --noEmit` is currently clean, so a CI gate on typecheck can land today;
gate on lint once the casts are converted.

### 6. Deployment reality

AI text and images run against `localhost` (Ollama :11434, ComfyUI :8188), and
the image route hands the browser a `localhost:8188` URL. Deployed, every AI
feature is dead. "Deployed GetGoGone" and "working GetGoGone" are currently
different products.

## Recommended order

1. Decide auth. It gates who can safely touch the app at all.
2. Ship `POST /api/v1/leads` on AutoDoss, then execute the staged deletions.
3. Collapse nav to the focused set from `REDESIGN_2026-06.md`.
4. Build **one** real distribution channel end to end — Meta Advantage+ catalog
   feed. One working channel is worth more than four simulators.
5. Then Remotion video.
